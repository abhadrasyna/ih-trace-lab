# CTAP/SM-VOD retention

`investigations/ctap-smvod/` is a rolling recurring campaign, not a one-off case file. Keep the folder open-ended: new dates append fresh raw exports into `data/`, regenerate per-date `output/`
artifacts, and update the dated docs under `docs/` as the campaign continues.

There is no planned close-out date for this investigation. Retain the structure, scripts, and historical outputs so future dates can be re-run with the same pipeline and compared against prior runs.
